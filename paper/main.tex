\begin{abstract}
Does adding context hurt a small language model, and do the location and topicality of that context matter? We test the frozen \modelName{} artifact on \sampleSize{} deterministic synthetic contract-clause probes spanning mean prompt lengths of \tierTwoTokens{}, \tierFourTokens{}, and \tierEightTokens{} tokens. Moving the same answer-bearing clause from the start to the end raised accuracy by \positionTwoStartEndChange{} percentage points at the shortest tier and \positionFourStartEndChange{} points at the middle tier, while keyword pruning lowered matched accuracy by \pruningChange{} points. The matched amount comparison was inconclusive: accuracy rose by \amountSharedTwoFourChange{} points and then changed by \amountSharedFourEightChange{} points, with only \amountSharedEightCount{} shared cases at each tier. For this model and task, end placement improved retrieval and a keyword filter amplified the lexical trap, while the amount experiment could not establish whether longer context helped or hurt.
\end{abstract}

\section{Introduction}

You paste a long contract into a chatbot and ask, ``What code renews the vendor agreement?'' The answer sits in one clause, but a similar buyer clause repeats the words in your question and gives a different code.

Long prompts make this ordinary lookup less predictable. A model may fail because the document is longer, because the answer appears in a weak position, or because nearby text resembles the question. Those explanations imply different choices: shorten the prompt, move the key clause, or filter the document. A useful evaluation must vary each property while holding the others fixed.

We study these choices in a synthetic, gradeable version of the contract situation. Each document contains an answer-bearing vendor clause and a look-alike clause for another company. The question uses the wording of the look-alike clause, while the answer clause expresses the same relation with different words. This construction reduces the value of literal matching, following the motivation of NoLiMa \citep{modarressi2025nolima}.

Our contribution is a fully paired, laptop-scale evaluation of a frozen open model. Prior work established position and length failures in larger systems \citep{liu2023lost,levy2024same}, and showed that irrelevant statements can disrupt reasoning \citep{shi2023distracted}. We instead compare topically related and unrelated filler at matched prompt lengths, positions, and questions. We also test whether a deterministic keyword filter helps the exact cases on which the unfiltered model was evaluated.

The experiment asks four questions:
\begin{enumerate}
    \item As the document grows from \tierTwoTokens{} to \tierEightTokens{} mean tokens, how much does accuracy change on shared cases?
    \item How does moving the same answer clause among the start, middle, and end change accuracy?
    \item Does topically related filler hurt less than unrelated filler in matched documents?
    \item Does keyword pruning recover accuracy on matched full-context cases?
\end{enumerate}

The answer is not a general context-length threshold. In this grid, the model improved when the answer appeared near the end, related filler was no safer than unrelated filler, and keyword pruning amplified the lexical trap built into the probes.

\section{Related Work}

\citet{liu2023lost} found a U-shaped position curve in multi-document question answering and key-value retrieval, with stronger use of information near context boundaries. Our design performs a smaller clause-reordering test: the question, filler, competing clause, and answer code remain fixed while only the answer clause moves. The observed pattern is primarily recency rather than a full U-shape because the start condition is also weak.

Input amount can matter even when the underlying problem is fixed. \citet{levy2024same} padded matched reasoning problems and observed degradation well before model context limits, while RULER found that usable context lengths can be shorter than advertised windows \citep{hsieh2024ruler}. Our amount comparison uses the intersection of cases present at every tier, avoiding a change in scenario mix as prompts grow.

\citet{shi2023distracted} added irrelevant statements to arithmetic problems and found lower reasoning accuracy. We ask a different quality question: whether filler from the same business domain is less harmful than unrelated prose when amount and question wording match. NoLiMa shows why literal needle tests can overstate retrieval ability \citep{modarressi2025nolima}; our answer clause therefore paraphrases the question while a competing clause shares its surface form. The tested model belongs to the instruction-tuned Qwen family \citep{qwen2024qwen25}.

\section{Probe Design}

\paragraph{Model and execution.}
The subject is the frozen \modelFile{} artifact, with its SHA checksum shown below:

We run it through \texttt{llama-completion} with greedy decoding, zero temperature, and a fixed seed. The complete manifest contains \manifestProbeCount{} probes, each stored as one prompt and one raw output. Existing outputs are skipped on rerun, so interrupted inference resumes by stable probe identifier.

\paragraph{Scenario families.}
Seeded code generates a company, target code, competing company and code, question, and filler for each family. The question asks for the renewal code needed to extend the target company's contract. Its wording exactly matches the competing clause, whereas the answer-bearing clause calls the same value a renewal identifier. A matched literal control reverses these phrasings while retaining the same filler.

For each full-context family, we insert the answer clause near the start, middle, or end. Family generation does not use target position in any random seed. The competing clause is independently assigned to an earlier or later fractional depth and remains there across all three renders. Thus a paired position contrast changes only where the answer clause appears.

\paragraph{Amount and quality.}
The tokenizer, rather than a character estimate, determines prompt length. The three full-context tiers average \tierTwoTokens{}, \tierFourTokens{}, and \tierEightTokens{} tokens. Each tier balances topically related filler with unrelated sentences. Related filler consists of other companies, business records, and unrelated codes; unrelated filler describes places and events outside the contract domain. Quality pairs share the family, target position, question, and measured tier.

The expensive final tier contains fewer families. Amount estimates therefore use only the \amountSharedEightCount{} cases shared by every tier, not the unequal full-tier totals. Quality estimates use \qualityTwoRelevantDenominator{}, \qualityFourRelevantDenominator{}, and \qualityEightRelevantDenominator{} pairs at the three tiers, respectively.

\paragraph{Pruning and controls.}
At the middle tier, a keyword filter retains sentences with at least two content words shared with the question, falling back to the highest-overlap sentences if too few qualify. It preserves original order. The comparison is restricted to the \pruningDenominator{} cases with both full and pruned outputs. We also include \closedBookCount{} closed-book questions and \literalControlDenominator{} matched literal-versus-paraphrase controls.

\section{Scoring and Comparisons}

Normalized accuracy requires the target code to appear without the competing code. Exact-output compliance requires a response containing one code and no other text. A distractor capture contains the competing code without the target, and an invalid response contains both expected codes or neither. We strip only the runner's fixed transport trailer before applying these rules.

Every accuracy interval is a \confidenceLevel{}\% Wilson score interval. Paired changes are differences in accuracy over an exact intersection of scenario keys. We report wins, losses, and ties for these comparisons because the small denominators make an aggregate difference alone easy to misread. The experiment is descriptive of the frozen model and does not assign sampling uncertainty to decoding, which is deterministic.

\textbf{Keyword pruning backfired on the matched cases.} Full-context accuracy was \pruningFullAccuracy{}\%, compared with \pruningPrunedAccuracy{}\% after filtering, a change of \pruningChange{} points. \section{Limitations}

The findings concern one small quantized model and may not transfer to larger models or other quantization levels. Synthetic clause lookup is not natural contract analysis, and retrieval accuracy is not a measure of general capability. The \cpuBudgetMinutes{}-minute CPU budget capped the grid, leaving only \tierEightCount{} full-context probes at the longest tier and wide intervals throughout. That sparse tier prevents a conclusion about degradation within the measured range, and the experiment cannot address longer prompts. Greedy decoding removes run-to-run sampling variation but does not show how sampling would change the estimates. The mitigation is a deliberately simple keyword filter rather than a learned retrieval system.

\section{Reproducibility}

Every reported quantity is generated by analysis scripts from the committed probe manifest and raw model outputs, following the reporting principle that computational evidence should expose its budget and variation \citep{dodge2019show}. The model and cached data are frozen and checksummed, and each raw output retains its stable probe identifier. Running \texttt{make all} regenerates \texttt{results.json}, the LaTeX value macros, and the paper from cached outputs; running \texttt{make clean-deep \&\& make all} repeats deterministic model inference. Repository gates check frozen inputs, citation resolution, number provenance, pipeline freshness, result sanity, prose style, anonymity, and compilation.
