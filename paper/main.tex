\begin{abstract}
Where an answer appears and which competing text survives selection may govern clause retrieval more clearly than prompt length in a small language model. We evaluate the frozen \modelName{} artifact on \sampleSize{} deterministic synthetic contract-clause probes spanning mean prompt lengths of \tierTwoTokens{}, \tierFourTokens{}, and \tierEightTokens{} tokens. Moving the answer clause from the start to the end raised accuracy by \positionTwoStartEndChange{} points at the shortest tier and \positionFourStartEndChange{} points at the middle tier. Keyword pruning reduced accuracy from \pruningFullAccuracy{}\% to \pruningPrunedAccuracy{}\% because it retained a clause whose wording matched the question but whose code was wrong. A query-entity selector excluded that lexical decoy and reached \entitySelectorAccuracy{}\% accuracy on the same \entitySelectorCount{} cases. The matched length comparison remained inconclusive, so the practical finding is narrower: test a cheap selector against plausible lexical competitors before using it to shorten documents for this model.
\end{abstract}

\section{Introduction}

You paste a long contract into a chatbot and ask, ``What code renews the vendor agreement?'' The answer sits in one clause, but a similar buyer clause repeats the words in your question and gives a different code.

This ordinary lookup becomes less predictable in a long prompt. The model may fail because it must process a longer document, because the answer appears in a weak position, or because nearby text resembles the question. Each explanation points to a different diagnosis: compare matched prompt lengths, move the key clause, or inspect what a filter retains. Distinguishing among them requires an evaluation that holds scenario content fixed across comparisons.

We study these choices in a synthetic, gradeable version of the contract situation. Each document contains an answer-bearing vendor clause and a look-alike clause for another company. The question uses the wording of the look-alike clause, while the answer clause expresses the same relation with different words. This construction reduces the value of literal matching, following the motivation of NoLiMa \citep{modarressi2025nolima}.

We provide a paired evaluation of a frozen open model at laptop scale. Prior work established position and length failures in larger systems \citep{liu2023lost,levy2024same} and showed that irrelevant statements can disrupt reasoning \citep{shi2023distracted}. Our main comparison moves the same answer clause while preserving the question, clause wording, codes, and filler order. We then compare a deterministic keyword filter with a query-entity selector that keeps sentences naming the company in the question. This selector comparison tests whether shortening helps when the filter does or does not retain the lexical competitor.

The experiment asks three questions:
\begin{enumerate}
    \item How does moving the same answer clause among the start, middle, and end change accuracy?
    \item How much accuracy do keyword overlap and query-entity selection preserve on the same cases, and which clauses do they retain?
    \item As mean prompt length grows from \tierTwoTokens{} to \tierEightTokens{} tokens, how much does accuracy change on shared cases?
\end{enumerate}

Within this grid, accuracy was higher when the answer appeared near the end. That placement result is diagnostic because using it requires knowing the answer location. The deployable query-entity selector instead avoided the lexical trap that keyword pruning amplified, while the matched length comparison did not identify a degradation threshold.

\section{Related Work}

\citet{liu2023lost} found a U-shaped position curve in multi-document question answering and key-value retrieval, with stronger use of information near context boundaries. We conduct a smaller clause-reordering test in which the question, filler sequence, clauses, and codes remain fixed while we insert the answer clause at a different depth. When we place it before the competing clause, the competing clause's final sentence index shifts by one. The resulting pattern mainly favors recent information rather than forming a full U-shape, because accuracy is also low in the start condition.

Prompt length can matter even when the underlying problem is fixed. \citet{levy2024same} padded matched reasoning problems and observed degradation well before model context limits, while RULER found that usable context lengths can be shorter than advertised windows \citep{hsieh2024ruler}. Our prompt-length comparison includes only cases present at every tier, so the mix of scenarios remains fixed as prompts grow.

\citet{shi2023distracted} added irrelevant statements to arithmetic problems and found lower reasoning accuracy. Our filler bundles vary several properties together, so we use them to balance the main comparisons rather than to claim an isolated relevance effect. NoLiMa shows that synthetic retrieval tests based on literal word matches can overstate retrieval ability \citep{modarressi2025nolima}. We therefore paraphrase the question in the answer clause while giving the competing clause the same surface wording as the question. The tested model belongs to the instruction-tuned Qwen family \citep{qwen2024qwen25}.

\paragraph{Model and execution.}

We run it through \texttt{llama-completion} with greedy decoding, zero temperature, and a fixed seed. The complete manifest contains \manifestProbeCount{} probes, each stored as one prompt and one raw output. Existing outputs are skipped on rerun, so interrupted inference resumes by stable probe identifier.

\paragraph{Scenario families.}
For each family, seeded code generates the target company and code, a competing company and code, a question, and filler. The question asks for the renewal code needed to extend the target company's contract. Its wording exactly matches the competing clause, whereas the answer-bearing clause calls the same value a renewal identifier. A matched literal control reverses the wording of the two clauses while retaining the same filler.

For each full-context family, we insert the answer clause near the start, middle, or end. Family generation does not use target position in any random seed. We assign the competing clause a fractional insertion index, either earlier or later in the document, that is independent of answer position and fixed across the three versions. Its final sentence index shifts by one when the answer is inserted before it. Thus, each paired position contrast changes both the answer placement and this mechanical one-sentence shift while preserving the scenario content and filler order.

\paragraph{Amount and filler control.}
The tokenizer, rather than a character estimate, determines prompt length. The three full-context tiers average \tierTwoTokens{}, \tierFourTokens{}, and \tierEightTokens{} tokens. Each tier balances business filler with unrelated sentences. Business filler consists of other companies, records, and unrelated codes; unrelated filler describes places and events outside the contract domain. Filler pairs share the family, target position, question, and measured tier.

This manipulation changes several properties together. Compared with unrelated prose, the related filler contains more business entities, contract-like templates, and code-shaped answer candidates. The paired comparison therefore identifies the effect of these two generated filler conditions, not the effect of topical relevance alone.

The final tier contains fewer families because it is more expensive to run. Prompt-length estimates therefore use only the \amountSharedEightCount{} cases shared by every tier rather than the unequal full-tier totals. We balance both filler bundles within each reported position and length comparison but do not interpret their contrast as a context-quality effect.

\paragraph{Selectors and controls.}
At the middle tier, a keyword filter retains sentences with at least two content words shared with the question, falling back to the highest-overlap sentences if too few qualify. A second selector extracts the company named after ``contract with'' in the question and keeps sentences containing that name. If extraction or matching fails, it falls back to the keyword filter. Both rules use only visible text, preserve original order, and require no answer labels. The comparisons are restricted to the \pruningDenominator{} cases with full context and both selector outputs. We also include \closedBookCount{} closed-book questions and \literalControlDenominator{} matched literal-versus-paraphrase controls.

The keyword filter retained the answer clause and lexical decoy in all \pruningPrunedCount{} matched prompts. The query-entity selector retained the answer clause in \entitySelectorTargetRetainedCount{} prompts and the decoy in \entitySelectorDistractorRetainedCount{}. A paired diagnostic removes only the decoy from each keyword-pruned prompt, leaving every other selected sentence fixed. This diagnostic uses the known synthetic label; both automatic selectors do not.

\section{Scoring and Comparisons}

Normalized accuracy requires the target code to appear without the competing code. Exact-output compliance requires a response containing one code and no other text. A distractor capture contains the competing code without the target, and an invalid response contains both expected codes or neither. We strip only the runner's fixed transport trailer before applying these rules.

We report descriptive results for the observed seeded scenario families. Each accuracy appears with its probe and family counts. Paired changes use the exact intersection of scenario keys and include wins, losses, and ties, where a win is a case corrected by the second condition and a loss is a newly incorrect case. The grid contains only \tierEightFamilyCount{} to \tierTwoFamilyCount{} families per full-context tier, which does not support a population confidence claim. Greedy decoding is deterministic, so repeated decoding adds no sampling uncertainty.

\section{Limitations}

The findings concern one small quantized model and may not transfer to larger models or other quantization levels. Synthetic clause lookup is not natural contract analysis, and retrieval accuracy is not a measure of general capability. The \cpuBudgetMinutes{}-minute CPU budget capped the grid, leaving only \tierEightCount{} full-context probes at the longest tier and few families throughout. The estimates describe those observed families rather than a broader generator population. That sparse tier prevents a conclusion about degradation within the measured range, and the experiment cannot address longer prompts. The filler comparison confounds topical relation with semantic domain, entity and code density, candidate count, and sentence templates. A factorial design that matches those properties would be needed to identify a topical-relevance effect. Greedy decoding removes run-to-run sampling variation but does not show how sampling would change the estimates. Query-entity selection assumes that the question names one company exactly and that the relevant sentence repeats that name. It does not address aliases, pronouns, or queries without a unique named subject. The decoy-removal control also depends on an oracle label unavailable in natural documents.

\section{Reproducibility}

Analysis scripts generate every reported quantity from the committed probe manifest and raw model outputs. This procedure follows the principle that reports of computational evidence should expose their budget and variation \citep{dodge2019show}. The model and cached data are frozen and checksummed, and each raw output retains its stable probe identifier. Running \texttt{make all} regenerates \texttt{results.json}, the LaTeX value macros, and the paper from cached outputs; running \texttt{make clean-deep \&\& make all} repeats deterministic model inference. Repository gates check frozen inputs, citation resolution, number provenance, pipeline freshness, result sanity, prose style, anonymity, and compilation.
